# learn-cicd-starter

This is a starter project for learning CI/CD concepts.

## Features
- Automated testing with Go
- CI/CD pipeline with GitHub Actions
- Code formatting checks

## Getting Started
1. Clone the repository
2. Run `go mod tidy`
3. Run `go test ./...` to run tests
